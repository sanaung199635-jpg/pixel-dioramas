# 仰光大金塔 · Shwedagon 3D Pixel Art Diorama

Three.js (r160) 等距像素风微缩沙盘：金色主塔、陪塔、缅式门楼与殿亭、跪拜的朝圣者、绕塔的僧侣，摆在纯白背景中央。

## 运行

```bash
python -m http.server 8080
```

然后打开 http://localhost:8080（ES Module 需要本地服务器，不能直接双击 html）。Three.js 通过 importmap 从 CDN 加载，无需安装。

## 操作

| 操作 | 效果 |
| --- | --- |
| 鼠标左键拖动 / 单指拖动 | 旋转视角（OrbitControls，带平滑阻尼，俯仰角受限，不会穿到地面以下） |
| 滚轮 / 双指捏合 | 以光标为中心缩放 |
| 右键拖动 / 双指拖动 | 平移 |
| 点击人物 | 柔和金色高光 + 光环与金色粒子反馈，镜头平滑拉近，弹出人物卡片；人物会自动低头礼佛或合十回应 |
| 人物卡片按钮 | 站立 / 双手合十 / 跪拜（跪下并三次叩首）/ 低头礼佛 / 起身，多人可同时做不同动作 |
| 点击建筑 | 主塔、礼拜殿、环塔佛塔、礼拜亭、阶梯入口、石狮、灯龛均可点击，弹出名称与历史介绍 |
| 关闭卡片 / 点击空白 / `Esc` | 取消选择，镜头回到之前的视角 |
| 底部工具栏 | 旋转（每次 90°）· 放大 · 缩小 · 重置 · 自动观赏（绕沙盘缓慢旋转）· 信息（导览） |
| 右上角 `EN / 中` | 中英文切换（会记住选择） |
| 右上角 高清/标准/复古、`P` | 像素精度 |
| 场景导航 / 键盘 `1`–`4` | 晨曦礼佛 / 正午金光 / 黄昏诵经 / 夜色金塔 |
| `R` / `0` | 旋转 90° / 重置视角 |

点击与拖动是分开处理的：按下鼠标时事件先被拦住，只有移动超过 6 像素才交给 OrbitControls 旋转；没有移动就当作点击去拾取，所以点人物时镜头不会被带着转。

## 内容说明

- **人物均为虚构的演示角色**（卡片上带“虚构演示内容”标记），名称为“演示角色 · 信众 07”这类编号，不对应任何真实的游客或僧人。数据在 `src/data.js` 的 `makePersonData`。
- **建筑历史**（`src/data.js` 的 `BUILDINGS`）只使用公开资料中有记载的内容，传说与考古推断分开表述；参考 Wikipedia「Shwedagon Pagoda」与 Encyclopaedia Britannica 条目。模型是艺术化简，建筑数量与位置不代表真实布局。

## 代码结构

| 文件 | 作用 |
| --- | --- |
| `src/main.js` | 渲染器、OrbitControls、拾取与点击/拖动分离、选中高光与粒子、GSAP 镜头过渡、信息卡片、工具栏、语言切换、主循环 |
| `src/people.js` | 统一人物骨骼（站立 ↔ 跪坐可混合），GSAP 动作时间线，共享几何体/材质缓存，隐形点击包围盒 |
| `src/data.js` | 中英文界面文案、建筑历史、虚构人物数据 |
| `src/pagoda.js` | 主塔、佛龛、尖塔、殿亭、石狮等建筑构件，`tag()` 标记可点击建筑 |
| `src/world.js` | 台座、栏杆、台阶、广场布局、绿化 |
| `src/pixel-renderer.js` | 低分辨率像素化渲染管线 |
| `src/effects.js` / `presets.js` / `textures.js` | 香烟与飞鸟、四个时段光照、像素贴图 |

GSAP 3.12 通过 importmap 从 jsDelivr 加载。

## 场景构成

- **台座**：一整块抬高的大理石广场（白/米色棋盘砖），四周灰色石砌墙、金色檐线和白色栏杆（金色宝顶），墙面垂下绿植。前方两处台阶，台阶上下各有一对金色石狮 chinthe，台阶顶端是金白尖塔门殿。
- **大金塔**（`src/pagoda.js`）：五层八角阶梯基台（每层一圈金色小尖塔）→ 16 层带金檐的钟形塔身 → 头巾环 → 覆钵 → 莲瓣 → 12 节尖顶 → 红色箍带、宝伞、小铃、十字风标、钻石宝珠。四个斜角各有一座大型礼拜龛。金色表面使用像素“金砖”贴图 + 环境反射金属材质，呈现体素颗粒感，是全场最亮的视觉中心。
- **塔周**：紧贴塔基的一圈白金尖塔佛龛（多层金顶、角上小尖塔，龛内金佛发光），外圈一圈金色小尖塔和绕塔步道，后半场再加一圈尖塔佛龛。
- **广场陈设**：信众之间散布红柱金顶灯龛；四周沿边交替摆放花槽、金色尖塔柱和灯柱。
- **周边建筑**：多座绿瓦金边的缅式多层屋顶殿亭（红柱、殿内金佛）、白金佛塔、边角小龛。
- **供奉**：香炉（带香烟）、供桌（鲜花、烛火）、金顶灯柱、花槽。
- **人物**（`src/people.js`）：大部分是跪在红色拜垫上、面向大金塔成排祈祷的信众，双手合十，其中一部分会周期性叩拜伏地；少量手捧鲜花站立的朝圣者；橙色、酱红袈裟的僧侣和粉衣尼姑沿步道顺时针绕塔。
- **绿化**：广场后排的棕榈树、开花树（种在红色花坛里）、沿栏杆的修剪绿篱。另有白鸽绕塔尖盘旋。

## 渲染管线（`src/pixel-renderer.js`）

低分辨率离屏渲染（Nearest）→ 法线/深度边缘描边 → 深度二阶差分环境遮蔽 → 调色 → 有序抖动量化 → 按整数像素放大到屏幕。像素块始终是整数大小，旋转、缩放时保持清晰的像素边缘。

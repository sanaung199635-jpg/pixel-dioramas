# 便利店微缩沙盘 · Convenience Store Pixel Diorama

Three.js (r160) 等距像素风微缩场景：一家 24 小时营业的便利店，透过落地玻璃能看到店内，带晴天 / 下雨 / 下雪天气系统和白天 / 夜晚切换。

## 运行

```bash
python -m http.server 8080
```

然后打开 http://localhost:8080（ES Module 需要本地服务器）。Three.js 通过 importmap 从 CDN 加载，无需安装。

## 操作

| 操作 | 效果 |
| --- | --- |
| 底部胶囊：晴天 / 下雨 / 下雪 | 切换天气，光照、地面湿度、积雪平滑过渡（键盘 `1` `2` `3`） |
| 透视（眼睛图标） | 像娃娃屋一样把屋顶和招牌整体抬起，俯看完整店内布局（键盘 `X`）；点击店铺时也会自动抬起 |
| 白天 / 夜晚 | 夜晚店内灯光、招牌、路灯亮起，积水映出暖光（键盘 `N`） |
| 拖动 / 滚轮 / 双指 | 小幅旋转（方位与俯仰都限制在店面朝向镜头的范围内）、缩放 |
| 点击人物 | 金色高光，镜头靠近，卡片显示姓名、身份、正在做什么（实时） |
| 点击店铺 | 卡片显示店名、营业状态、当前天气、店内人数（实时） |
| 悬停 | 人物或店铺轻微高亮并显示名称 |
| 右上角 高清/标准/复古、`P` | 像素精度 |
| `Esc` / `0` | 关闭卡片 / 重置视角 |
| URL 参数 | `?weather=rain`、`?weather=snow`、`?time=night`、`?view=inside`，可组合 |

## 场景

- **店铺**（`src/store.js`）：落地玻璃立面（前侧两面）、自动感应玻璃门、门头白底三色条纹招牌与灯箱、屋檐筒灯、屋顶空调与女儿墙。
- **店内**：两面墙的饮料冷柜（瓶子用 InstancedMesh）、零食与泡面双面货架、便当冷藏台、收银台（收银机、热食柜、关东煮）、两台微波炉、烟柜与价目牌、自助咖啡角、杂志架、天花灯与暖色店内灯光。
- **地块**（`src/world.js`）：深色底座 → 混凝土地基 → 地面；停车位（含无障碍车位）、车挡、店前地砖、人行道与路缘、两辆小车、摩托车、自行车与车架、两台自动售卖机、立柱招牌、垃圾桶、冰柜、A 字立牌、树、路灯、电线杆与电线。
- **人物**（`src/people.js`，均为虚构角色）：收银员、扫码付款的顾客、挑零食的顾客、挑饮料的顾客、骑摩托来买便当再离开的顾客（会触发自动门）、人行道上的路人（下雨打伞快步走、下雪放慢）、门口屋檐下等人/避雨的人；下雪时会戴上围巾。
- **天气**（`src/weather.js`）：
  - 下雨：InstancedMesh 雨丝、屋檐滴水、地面与屋顶溅起的水圈、玻璃上滑落的水珠、反光积水、地面变暗变光滑。
  - 下雪：缓慢飘落、随风摆动的雪花，地面斑驳积雪，屋顶、招牌、车顶、售卖机、树冠等处逐渐积雪；停雪后慢慢融化。

## 关于“看到店内”

在 30° 俯角的等距视角下，任何有屋顶的建筑都只能透过玻璃看到靠窗约 3 个单位深的区域，所以：

1. 店内重要陈设（货架、便当台、收银台、咖啡角）都排在靠窗的可见带里；
2. 额外提供“透视”模式，把屋顶连同门头招牌一起抬起，完整展示店内。

门头标识是风格化演绎，并非官方素材。

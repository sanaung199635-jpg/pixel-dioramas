## 1. 对《JADE GENESIS》的视觉理解

这不是一个“产品介绍页”，而是一间**可以走进去的数字工艺馆**：观众面前始终只有**一块石头**，它在十二个工位之间移动、被切开、被取圈、被打磨，最终成为一只手镯。

三条设计原则贯穿全部画面：

1. **一块石头，一个坐标系。** 原石内部的颜色、棉絮、色带与一条贯穿裂隙，全部由同一个三维纹理场决定。切面、板料、镯芯、镯坯和成品手镯都从这个纹理场“取材”，所以切开后看到的内容与切开前的石头在逻辑上一致；画圈时两只镯圈会主动避开那条裂隙。这在概念图中已经实现（见 §3）。
2. **博物馆的克制。** 翡翠绿是画面中唯一的饱和色。背景、机械、展台全部退后为中性色，光线柔和、阴影真实，不做炫光、不做霓虹、不滥用玻璃拟态。
3. **工艺先于特效。** 每一幕都要让观众一眼看懂“这一步对石头做了什么”。镜头运动服务于空间逻辑：上一镜的结束机位就是下一镜的起点。

## 2. 两套视觉方案

| | 方案 A · WHITE JADE GALLERY（推荐） | 方案 B · DARK GEMSTONE MUSEUM |
|---|---|---|
| 空间 | 暖白无缝展厅（`#F1EEE8`），漂浮圆台 | 黑曜石展馆（`#0C0E0F`），金属描边展台 |
| 光线 | 柔和主光 + 天光 + 背光，大面积柔和接触阴影 | 顶部聚光 + 翡翠色轮廓光（限定照射主体） |
| 机械 | 暖白搪瓷 + 鼠尾草绿点缀 + 拉丝钢 | 石墨灰搪瓷 + 深色钢 + 黄铜细节 |
| 气质 | 轻盈、清晰、收藏模型感 | 神秘、昂贵、珠宝级 |
| 优势 | 工艺细节、水流、切面边界最清楚；长文阅读舒适 | 成品手镯的透光与高光最有戏剧性 |
| 风险 | 成品镜头的“珠宝感”略弱 | 暗场吞掉机械与工艺细节；小字对比度风险 |

**可选混合：** 全程使用 A；只在第 12 幕“成品展厅”切换为 B 式的暗场聚光，作为整段旅程的高潮。

### 设计系统草案

- **主色：** 翡翠绿 `#2B7351`（A）/ `#3FCF8B`（B）；警示 / 待审核色 `#9A6B2F`。
- **字体：** 标题 Noto Serif SC（宋体气质），正文 Noto Sans SC。*概念图因渲染环境限制使用文泉驿正黑代替。*
- **布局（桌面）：** 顶栏（品牌 / 章节 / 声音 / 语言）· 左侧工序卡 · 右侧知识卡 · 底部 12 段时间轴 · 右下浮动控制（暂停、0.5×/1×/2×、重置、视角）。
- **布局（移动）：** 画布优先；标题浮于上方；操作收进底部抽屉；时间轴压缩为 12 个编号点；最多同时显示 2 个热点标注。并非桌面版的等比缩小。
- **热点标注：** 圆点 + 光晕 + 折线引线 + 半透明标签。

## 4. 故事板摘要（12 镜头）

| # | 工序 | 镜头运动 | 关键动作 | 互动 |
|---|---|---|---|---|
| 01 | 开采 | 等距俯瞰，环绕 30°，推近挖斗 | 挖斗抬起原石，原石“飞入”展台 | 点击挖掘机 / 矿坑 / 原石 |
| 02 | 清洗 | 由高位下降至 45° 中景 | 石皮由干变湿、颜色加深 | 拖动水枪 |
| 03 | 打灯观察 | 环境变暗，推近特写 | 手电沿表面移动，局部透光 | 拖动手电；固定提示“打灯有局限” |
| 04 | 开窗 | 侧前方，缓慢推近 | 砂轮磨去局部石皮 | 点击窗口 → 放大镜视图 |
| 05 | 切割规划 | 360° 慢环绕 + 正交切换 | 依次画出切割线（先对半，再取板） | 切换视图 |
| 06 | 水冷切片 | 全景 → 锯片接触点特写 → 拉远 | 下切、水雾、两半如书页打开 | 点击设备；切面放大 |
| 07 | 画圈 | 俯视正交 | 灯箱透光，画同心圆并避开裂隙 | 悬停圆圈看尺寸 |
| 08 | 套取镯坯 | 侧向剖视 | 管钻下行，分离出镯坯 / 镯芯 / 余料 | 点击三件分别标注 |
| 09 | 粗加工 | 中景跟随 | 方截面修成圆角条形 | 截面剖视切换 |
| 10 | 精磨 | 近景跟随 | 磨砂表面逐渐变平整 | 前后对比滑块 |
| 11 | 抛光 | 极近特写，光源掠过 | 高光由模糊变锐利 | 拖动光源角度 |
| 12 | 检查展示 | 慢速 360° | 灯照、卡尺检查后陈列 | 360°、缩放、聚光切换 |

## 5. 视觉设计的专业审查意见（自评）

**做得好的地方**

- **材料连续性已在概念阶段验证。** 切面、板料、镯坯、成品共用同一个纹理场；那条贯穿裂隙在石皮、窗口、两个切面和板料上的位置一致。这条技术路线可以直接用于 Phase 3。
- **翡翠不是玻璃。** 成品手镯有浓淡不均的绿色、白色棉絮、细小深色包体和半透明度，没有做成全透明绿环。
- 方案 A 在所有工序中都能清楚辨认主体与动作；12 帧缩略图串起来就能读懂整个流程。

**需要坦白的不足（Phase 3 必须解决）**

1. **机械仍是“精致的简化模型”。** 由圆角盒、圆柱、管道组合而成，比例合理但缺少螺栓、铭牌、线缆、磨损等细节，还达不到“工业级”。正式开发需重新建模（或使用有明确授权的模型）。
2. **开窗区域在某些角度偏白、偏“雾”。** 原因是浅色底材 + 高透射率 + 白色背景；需要调整窗口区的透射、粗糙度与抛光。
3. **没有真正的次表面散射。** 目前用透射 + 衰减色近似“糯感”，边缘透光在 A 方案中偏弱。Phase 3 需要评估厚度图或自定义 SSS 近似。
4. **水流是粒子拼出的。** 静帧尚可，动起来需要专门的水流 / 水雾方案。
5. **粗坯表面的“粗糙感”是噪声凹凸，** 看起来更像颗粒而不是磨痕，需要方向性的磨削纹理。
6. **热点标注没有自动避让，** 移动端仍有引线交叉。
7. **矿坑侧壁的地层条纹有锯齿，** 坑底水面不明显。
8. **性能未验证。** 渲染使用 CPU 版 WebGL（SwiftShader），单帧 6–17 秒，**这些数字不代表任何真实设备的帧率**。

## 6. 下一阶段（Phase 2）需要研究和核实的翡翠知识

以下内容在概念图中被**引用或暗示**，目前全部标记为“待审核”，必须对照 GIA 等权威资料核实：

**矿物与定义**
- 硬玉（jadeite，辉石族）与软玉（nephrite，闪石族）的定义、区分方式，以及“翡翠”一词对应硬玉的口径。
- 概念图首页引用的数据：折射率约 1.66、摩氏硬度约 6.5–7。需核对，并决定是否加入比重等数据。
- 绿色的成因（含铬等致色元素）。表述需要谨慎。

**原石与开采**
- 主要产地（缅甸为主）与原生矿 / 次生矿（河流冲积、砾岩层）的区别。
- 实际开采方式：大型露天机械开采 vs 小规模开采。场景必须标注“示意”，并评估是否需要提及矿区安全与环境议题。
- 石皮的成因与厚度范围。概念图已删除未经核实的“3–5 mm”说法。

**观察与切割**
- 打灯观察的原理与局限，开窗 / 擦口的做法与术语。
- 切割设备：金刚石圆锯片与其他切割方式（如大型原石用的线锯？）、冷却液类型、切割方向的决策逻辑。
- 切割规划：先对半剖开再取板料，这个顺序是否具有代表性？

**取圈与成型**
- 画圈的依据（裂、色、尺寸）、常见圈口尺寸（内径）、条宽 / 条厚、截面类型（圆条 / 扁条 / 贵妃等）。
- 套取设备：单管还是双管钻？是否同时切内外圈？镯芯的后续用途。
- 粗加工 → 精磨 → 抛光的真实工序、设备形式与磨料目数顺序；概念图中“芯轴 + 砂轮”的固定方式需核实。
- 抛光材料与方法。

**品质与处理（必须严格区分）**
- GIA 的翡翠品质因素（颜色、透明度、质地、净度、切工 / 做工）。
- 天然未处理翡翠（常称 A 货）与漂白充胶（B 货）、染色（C 货）的定义。抛光属于正常加工，不是“处理”；处理状态只能靠检测确定，概念图已如此表述。
- 术语：棉、裂、纹（愈合裂隙）、种、水、色根等，中英对照，并核实其使用口径。

**参考来源（待逐条核对）：** gia.edu/jade、gia.edu/jade-description、gia.edu/jade-quality-factor、gia.edu/jade/buyers-guide；必要时补充宝石学教材或行业资料，并标明“示意简化”与“不代表所有工厂”。

# JADE GENESIS — 架构说明（Phase 4 · 完整 12 幕）

## 技术栈

| 层 | 选择 | 理由 |
|---|---|---|
| 构建 | Vite 6 + TypeScript 5.7（strict） | 快速开发；产物是纯静态文件 |
| 3D | Three.js 0.170（WebGL 2） | PBR 材质、透射、裁切平面、着色器注入 |
| 动画 | 自写的“进度 → 状态”纯函数（Director） | 跳转、暂停、倍速、自动导览的结果必须一致；目前不需要 GSAP |
| 声音 | WebAudio 实时合成 | 不需要音频文件，没有版权问题；默认关闭 |
| 测试 | Playwright 1.63 | 桌面与移动视口、交互、降级路径 |

运行时依赖只有 `three` 一个。

## 1. 一块石头，一个坐标系

`StoneSolid` 把原石定义为一个实体。每个网格顶点都带 `jpos`（在原石坐标系中的位置）和 `rim`（是否石皮），翡翠着色器只依赖 `jpos`。

| 工序 | 出现的部件 | 实现 |
|---|---|---|
| 01–05 | 整块原石 | `shellMorphGeometry`：`uFlat` 把外壳从原表面形变为带窗口的形状；`uReveal` 让窗口从中心向外“磨开” |
| 06 | 两半 A、B | 同一外壳 + 裁切平面 + 切面（`ClipPiece`） |
| 06 | B1、板料 S、B2 | B 再被 x0、x1 两个平面切开，由锯片依次完成 |
| 07 | 板料平放灯箱 | 马克笔画圈（着色器 `uMarks`，逐圈画出） |
| 08 | 镯坯、镯芯、余料 | 先外圈后内圈两次钻切（`uKerfs` 刀痕）；镯坯提出后板料上出现孔（`uHoles` + 孔壁），镯芯留在孔中 |
| 09–11 | 镯子 | `TurnedPiece`：同一个车削网格，截面从方（e≈0.1）连续变到圆（e=1），每一级都在上一级之内（只去料，不加料）；表面从粗糙到抛光 |
| 12 | 成品 | 真实比例展示；表面对比滑块只改变表面状态 |

那条命名裂隙出现在石皮、窗口、两个切面和板料上，位置一致；画圈时两组圈都避开了它。

## 2. Director：一个纯映射

`Director.apply(stage, progress)` 每帧做四件事：

1. 先把所有部件隐藏、把所有机器复位到静止状态；
2. 按当前工序设定一切：部件位置、机器动作、材质状态、灯光；
3. 早期工位留下的余料继续留在原处（切割机旁的两块余料、钻床上的板料与镯芯）；
4. 返回镜头、热点和声音音量。

**每一幕的开头，就是从上一幕终点出发的运送动作**：原石“飞入”清洗台，然后被送上展台、切割机；板料被送上灯箱、钻床；镯坯被送上磨床、展台。所以无论自动导览还是跳转，空间关系都连续。

只有锯片、砂轮的旋转和水滴随“机器时间”循环，它们不携带剧情状态。

## 3. 播放

- `Journey` 只保存数据。“开始旅程”进入导览模式：每幕结束后自动进入下一幕，第 12 幕结束后停止。
- 点击时间轴或上一道 / 下一道：单独播放该幕。
- 拖动进度条：暂停并跳到该位置。
- 倍速：0.5× / 1× / 2×。全程 1× 约 5 分钟。

## 4. 相机

- **导览模式：** 平滑跟随每幕的镜头关键帧。第 05 幕是环绕原石一周；第 12 幕在检查之后慢速环绕 360°。
- **自由模式：** 用户拖动后进入。目标点被限制在当前工位附近（±6 / ±5 单位）；切换工序时自动回到导览。
- 第 12 幕允许更近的缩放距离，以便看清细节。

## 5. 声音

`Sound` 用 WebAudio 实时合成五个声道：风 / 室内底噪、马达、水、研磨、抛光。Director 每帧给出各声道的音量。

- 只有用户点击“声音”时才创建音频上下文。
- 标签页切到后台时自动静音。

## 6. 降级与画质

- 自适应画质（DPR、阴影分辨率分 4 档）。
- 没有 WebGL 2：显示说明页。
- WebGL 上下文丢失：显示提示，恢复后继续。

## 7. 调试接口 `window.__jade`

`state()`、`start()`、`goTo()`、`restore()`、`seek()`、`play()`、`pause()`、`setSpeed()`、`torch()`、`lightMode()`、`compare()`、`resetView()`、`hotspots()`、`frames()`、`freeze()` / `unfreeze()`、`field()`。

测试和截图脚本都通过它驱动，与 UI 调用的是同一套操作。

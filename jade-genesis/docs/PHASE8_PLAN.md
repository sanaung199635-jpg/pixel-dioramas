## 2. 布局设计（Mobile-First）

### 断点（按内容确定，不按设备型号）

| 布局 | 条件 | 依据 |
|---|---|---|
| **紧凑（手机）** | 宽 < 760 px **或** 高 ≤ 500 px | 宽度低于 760 px 时，桌面两侧的卡片（340 + 280 px）与场景放不下；高度 ≤ 500 px 时，控制栏加阶段卡片会挤掉场景（横屏手机） |
| 紧凑 · 竖屏 / 横屏 | 宽高比 | 横屏时阶段卡片放在左侧，知识卡片改为右侧抽屉 |
| 平板竖屏 | 760–1179 px 宽，高 > 500，竖屏 | 保留常规面板，场景构图放到面板下方的空白区 |
| 常规（平板横屏、桌面） | 其余 | 与 v1.1 相同，不做改动 |

JavaScript 用同一个查询（`COMPACT_QUERY`）设置 `.ui[data-layout]`，CSS 按这个属性写规则，保证样式与相机构图始终一致。

### 紧凑布局的结构

- **顶部：** 品牌栏（48–50 px，加上刘海安全区）和 44×44 的声音按钮。
- **顶部浮动信息：** 阶段编号、标题、两行摘要，可以收起；知识卡片打开时暂时让位。
- **中间：** 3D 画布占满屏幕；主体被构图到界面空出来的区域里。
- **底部控制栏：**
  - 第 1 行：进度条，带阶段名和百分比。
  - 第 2 行：知识 · 上一幕 · 播放/暂停（56 px）· 下一幕 · 更多。
- **“更多”面板：** 速度 0.5×/1×/2×、打灯（第 03 幕）、重置视角、12 道工序网格（4×3，横屏为 6×2）。
- **知识卡片：** 独立的底部抽屉，默认收起，见下节。
- **首页：** 底部一张短卡片：标题、一句简介、“开始旅程”（主按钮）和“自由探索”（次级按钮）。矿场占据上方空间；首页不显示控制栏。

### 知识抽屉

| 状态 | 竖屏 | 横屏 |
|---|---|---|
| 关闭 | 移出屏幕，`visibility: hidden` | 同左 |
| 半展开 | 位于控制栏**上方**，约 40% 高；播放控制仍然可用 | 右侧抽屉，宽 min(380 px, 46vw) |
| 全展开 | 覆盖控制栏，只保留顶部品牌栏 | 右侧抽屉，加宽到 min(620 px, 72vw) |

- **操作：** 展开 / 收起按钮、关闭按钮、拖动头部（上拉展开，下拉收起）、Esc。
- **可访问性：**
  - 打开时焦点移到抽屉标题，关闭时焦点回到打开它的按钮。
  - `aria-expanded` 和 `aria-controls` 标注齐全，焦点轮廓可见。
  - 遵从 `prefers-reduced-motion`，关闭过渡动画。
- **内容：**
  - 先显示“要点”：加工目的和演示简化说明。
  - 下面完整保留专业术语、加工目的、设备、注意事项、参考来源和证据等级，**没有删除任何内容**。
- **内部独立滚动：** `overscroll-behavior: contain`，滚动不会带动页面。

## 3. 相机构图（不缩放网页）

- 每个停靠在边缘的面板，通过 CSS 自定义属性 `--avoid: top | bottom | left | right` 声明自己占用的边。
- `Ui.frameRect()` 从画布矩形中依次扣除这些面板，得到空出的区域。
- 知识抽屉单独处理：如果扣除后剩余区域太小（高度 < 25% 或宽度 < 35%），就不扣除，例如全展开时。
- `CameraRig.setFrame()` 用 `setViewOffset(区域宽, 区域高, -left, -top, 画布宽, 画布高)` 把镜头的取景映射到这块区域。场景在面板下方继续渲染，只是构图移动了。
- **视场角：**
  - 窄区域：保持设计时（16:10、30°）横向覆盖范围的 80%。
  - 宽区域：保持纵向覆盖范围的 115%。
  - 上限 64°，避免透视变形。
- 区域变化（抽屉打开、旋转、地址栏伸缩）时，构图以阻尼方式平滑过渡，不会跳变。
- **尺寸变化的监听：** `window resize`、`visualViewport resize` 和 `ResizeObserver(canvas)`。相同尺寸不会重复设置渲染器，也就不会重复创建 WebGL 资源。

## 5. 性能

- 保留 Phase 7 的全部优化：透射跳过、阴影分级、LOD 等。
- DPR 上限与画质分级没有改动：移动端起步档为 medium，DPR 上限 1.25。
- 新增开销：
  - 紧凑布局下每帧读取 5 个面板的矩形；
  - 构图区域变化时调用一次 `updateProjectionMatrix`。
- 不新增 WebGL 资源。
- 手机帧率**仍待实机测试**。

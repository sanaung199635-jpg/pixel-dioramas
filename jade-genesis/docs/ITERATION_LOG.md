## Phase 3 · 技术原型（上限 5 轮，实际 5 轮）

### Iteration 1 — 首次运行

- **目标：** 搭好项目，跑通“原石展台 → 运送 → 下切 → 打开切面”的完整流程。
- **修改：** 新建 `src/` 全部模块，`index.html`，`package.json`，配置文件。
- **验证：** `tsc --noEmit` 通过；在 1440×900 下截取 5 个状态（原石、打灯、切割 10% / 45% / 100%）。
- **发现：**
  1. 【阻塞】原石工位的热点在切割工位仍然显示：`.pin { display: flex }` 覆盖了 `hidden` 属性。
  2. 切割镜头太近：原石塞满画面，锯片被裁掉。
  3. 窗口整体发白，不像翡翠。
  4. 知识卡太高，遮住场景。
  5. 截图工具超时：CPU 渲染单帧约 0.3–0.9 秒，GPU 队列积压。
- **下一轮：** 修 1、2；为 3 建立对照实验；为截图加冻结接口。

### Iteration 2 — 镜头、热点与对照实验

- **目标：** 修复阻塞缺陷；重排镜头；找出窗口发白的原因。
- **修改：** `main.css`（`[hidden]` 规则、知识卡尺寸）、`CuttingScene.ts`（7 个镜头关键帧，拉远并保留锯片全貌）、`jadeShader.ts` / `JadeMaterial.ts`（新增 `uField` 内部纹理种子）、`App.ts`（`freeze()` + `gl.finish()`）。
- **验证：** 6 个种子变体对照截图；4 个切割进度截图。
- **结论：** 6 个种子的窗口都发白，说明问题不在纹理。热点问题已修复；切割全程镜头可读；切面揭示效果良好。
- **新问题：** 960 px 宽度下石皮出现像素马赛克；知识卡遮挡原石。

### Iteration 3 — 抗锯齿与布局

- **目标：** 消除石皮闪烁；中等宽度的布局。
- **修改：** `jadeShader.ts`（按像素尺度淡出高频颜色与凹凸 `aaFade` / `bumpFade`）、`main.css`（760–1179 px 时知识卡折叠为按钮）、`Coolant.ts` / `kit.ts`（水流加粗、提高不透明度）。
- **验证：** 对窗口做逐项排除实验：关闭边缘透光 → 仍白；关闭透射 → 仍白；粗糙度 0.6 → 绿色出现；降低环境反射与镜面强度 → 仍白。
- **结论：** 原因是平行主光照在**完全平整**的抛光面上，所有点的反射角相同，整片同时反光。
- **新问题：** 凹凸淡出过严，石皮变得像土豆皮。

### Iteration 4 — 窗口高光与暗房

- **目标：** 让窗口呈现翡翠而不是整片眩光；恢复石皮质感；打灯时的暗房效果。
- **修改：** `jadeShader.ts`（`uWave`：手工磨面的低频起伏；第一版频率过高，像保鲜膜，改为单一低频；石皮砂粒改由颜色表现）、`StonePieces.ts`（窗口 `wave: 1`，切面 `wave: 0.4`）、`Studio.ts`（暗房模式同时调暗背景、雾与清屏色）、`RoughStoneScene.ts` / `App.ts`（调试状态加 `exposure`）。
- **验证：** 桌面打灯截图：背景变暗，手电处出现绿色透光。探针测得曝光随时间收敛（0.94 → 0.67 → 0.45 → 0.05 → 0），说明此前“暗房没生效”的截图只是在渐变途中拍下的，问题在截图脚本，并非程序缺陷。
- **新问题：** 移动端打灯提示遮住故事卡；热点可能落在面板下面。

### Iteration 5 — 移动端与自动化测试

- **目标：** 移动端遮挡；自动化测试覆盖关键交互与降级路径。
- **修改：** `Ui.ts`（热点落在任何面板下时自动隐藏）、`main.css`（移动端提示移到底部）、`playwright.config.ts`、`tests/prototype.spec.ts`（14 个测试 × 2 个视口）。
- **验证：** 见 `QA_REPORT.md`。

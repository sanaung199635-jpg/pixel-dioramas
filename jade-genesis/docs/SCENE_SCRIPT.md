## 贯穿全片的物体

**同一块原石**（stone frame）。依次拆分为：两半原石 → 板料 → 镯坯 + 镯芯 + 余料 → 手镯。其中有一条贯穿裂隙（fissure plane），会出现在第 03、04、05、06、07 幕，必须在每一幕中位置一致。

## 转场规则

1. 每幕的结束机位就是下一幕的起点，不做硬切。只有 01→02 一处远距离位移，用“原石飞回展台”的动作承接。
2. 物体的拆分发生在画面里：切开、抬起、分离。不允许用突然替换或缩放来代替加工。
3. 所有动画由同一条可暂停的时间轴驱动；跳到任意一幕时，物体状态可以直接计算出来，不依赖前面的动画是否播完。

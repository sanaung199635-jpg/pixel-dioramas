## 验收维度

| 维度 | 结论 |
|---|---|
| 内容没有裁切 | 6 种尺寸、8 种状态下，检查到的控件都在屏幕内；知识内容一项未删，摘要放在最前 |
| 无横向溢出 | 所有状态都没有 |
| UI 不遮挡关键模型 | 相机按界面空出的区域构图；知识卡片打开时主体会避让（全展开时除外，此时是用户主动阅读） |
| 按钮可点击 | 触屏下所有控件都不小于 44 px；不再有被遮挡的按钮 |
| 字体清晰 | 正文 13–14 px；阶段标题 20 px；首页标题 28 px |
| 3D 模型构图合理 | 透视相机按空出区域取景；视场角上限 64°，避免变形 |
| 不需要无意义的滚动 | 页面不滚动；只有知识卡片和“更多”面板内部可以滚动 |

## 剩余问题

1. **真实 iPhone Safari 尚未验证**（环境没有 WebKit）。安全区、地址栏伸缩、橡皮筋滚动、触摸手势的实际表现需要在真机上确认。
2. **首页矿场在竖屏上偏小：** 为保证完整显示，约占宽度的 75%，上下留白较多。可以给首页单独调大覆盖比例，但要以真机观感为准。
3. **第 01 幕三个热点标签互相重叠**（挖掘机、翡翠原石、矿坑），这在 v1.1 也存在。可以在手机上只显示热点圆点。
4. **构图过渡在 CPU 渲染下较慢：** 真机上约 0.5 秒。降低动画偏好（reduced motion）的用户也会看到缓动，下一轮可以改为直接跳到位。

## 各项说明（可核对的改变）

### 地形结构
- **造型精度：**
  - v1.0 的台阶在方形网格上斜切，形成锯齿状的坎（before 局部图中最明显）。
  - 现在台阶边缘与网格行对齐，坎顶圆滑、岩面陡峭，坎脚有碎石裙。每一级台阶的高度不同（0.25–0.29），边缘各自起伏。
- **细节：**
  - 新增盘旋而下的运矿坡道、通向卡车的车辙土路、池边湿泥。
  - 约 150 块碎石沿坎脚分布，坑底和地表另有巨石。
- **材质：**
  - 地层改为逐像素计算：五种岩层、厚度不均、带褶曲和暗色夹缝，不再有 v1.0 侧面的马赛克色块。
  - 草地有两种绿色加干枯斑块；岩面、碎石和道路的粗糙度与法线各不相同。
- **构图：** 仍是同一块方形沙盘，尺寸和镜头都没有变。

### 挖掘机模型
- **造型：**
  - v1.0 由 9 个圆角方块组成，履带悬在台阶上方。
  - 现在由多个部件构成：
    - 底盘：48×2 块履带板、支重轮、驱动轮和导向轮。
    - 上车：转台、带百叶的发动机罩、圆形配重、有色玻璃驾驶室（带立柱）、扶手。
    - 工作装置：弯曲的箱形动臂、带尾部延伸的斗杆、弧形铲斗（侧板加 4 颗斗齿）。
    - 液压缸 4 根，随关节伸缩。
- **运行稳定性：**
  - 三个关节组的轴心和长度没有改变，挖掘动画与抓取原石的位置不受影响。局部图中原石正好落在新铲斗里。
  - 挖掘机站在与 v1.0 地面同高的作业平台上，履带不再悬空，也没有穿入地形。
- **成本：** 同一刚体组内、材质相同的静态网格已合并（见性能报告）。

### 原石材质
- **石皮：**
  - v1.0 的石皮是虫状起伏加大块白斑，读起来像海绵。
  - 现在是黄褐色的砂质皮壳：细密砂粒、灰白淋滤斑和深色风化斑，凹凸是宽缓的风化凹坑。
  - 第 02 幕的湿石皮对比最明显。
- **开窗面：** 摄影棚环境取代了 RoomEnvironment 的小方块灯，开窗面不再整片泛白。
- **剩余问题：** 开窗面现在不再泛白，但略显灰平，像雾面，玉的“水头”不够。可以进一步调整开窗面的透射和粗糙度，需要再做一轮对比。**未处理**，列入剩余问题。

### 翡翠切割面
- 底色从近乎白色调成半透明的灰绿；绿色略降饱和度，不再像薄荷或荧光色。
- 加入细微晶粒斑驳：硬玉是多晶集合体。
- 两半切面上的裂隙仍在同一位置（材质连续性没有被破坏）。

### 手镯材质
- **连续性修正：**
  - v1.0 的成品手镯使用绿色偏移 0.18，其他所有工件为 0.08。也就是说，同一块石头的同一个点，到了手镯阶段会突然变绿。
  - 现在所有工件统一使用 0.12。手镯比 v1.0 略淡，但颜色来自同一块石头的同一片区域。
- **高光：** v1.0 的高光被 RoomEnvironment 打碎成许多短条；现在是珠宝摄影棚柔光箱形成的连续长高光，表面光滑但不是镜面。
- **色调映射 A/B：**
  - 测试了 Neutral 色调映射：绿色更艳、接近荧光，白色地面变成奶油色。
  - 因此保留 ACES。对比所用的开关为 `__jade.look()`。

### 灯光与阴影
- **背光预设：**
  - v1.0 中背光与聚光几乎看不出区别。
  - 现在背光时环境反射降到 ×0.4，边缘透光提高。手镯呈深绿、带轮廓光，与聚光明显不同。
- **托架：** 改为暖灰褐色天鹅绒，绿色手镯与托架有了对比。
- **阴影稳定：** 阴影框在光源空间里按纹素对齐，镜头在工位间移动时阴影边缘不再闪烁。
- **开发中出现并已修复的问题：** 纹素对齐代码的第一版把阴影框放偏了，8 个工位中有 6 个没有投射阴影。经性能数据异常发现，已修复，并加了防回归测试（见 `PHASE7_ITERATION_LOG.md`）。
- **主要模型体积感：** 矿场的树、挖掘机、卡车在地面上都有投影（对比 intro / s01）。

### 手机显示
- 布局没有改动。矿场在 390 宽的屏幕上同样展示新地形、新挖掘机和新树木。
- 同一镜头下没有出现新的遮挡。

### 设备统一标准
- 清洗台、切割机、灯箱、钻床、打磨台的机身都加上了门板缝、螺栓和深色踢脚板。
- 不锈钢件统一使用拉丝粗糙度纹理，砂轮和磨筒使用磨料颗粒纹理。
- 见 `compare/desktop-s02.png`、`s06`、`s08`、`s09`、`s10`。

### UI 修正（v1.0 遗留）
- 键盘提示文字原本被底部操作栏遮住（before 截图中操作栏左上方能看到被截断的文字），现已移到操作栏上方。

## 验收维度汇总

| 维度 | 结论 |
|---|---|
| 造型精度 | 台阶、挖掘机、卡车、树木、机身细节都有实质提升；没有改变镜头和比例 |
| 材质可信度 | 石皮、玉肉、手镯、岩层、金属、磨料都换成了有依据的程序化材质；次表面散射仍是近似做法（边缘透光 + transmission + attenuation），**不是物理级模拟** |
| 视觉一致性 | 绿色偏移在所有工件间统一；所有设备使用同一套细节规范；白色画廊背景不变 |
| 场景构图 | 镜头关键帧不变；矿场仍是独立的方形沙盘 |
| 细节丰富度 | 碎石、坡道、液压缸、门缝与螺栓、砂粒等细节在局部图中可以看到 |
| 运行稳定性 | 控制台错误 0、HTTP 404 为 0；回归测试结果见下 |
| 性能成本 | 矿场三角形 ×2.4、draw calls +34%，其他工位约 ±10%。**帧率未实测**，见 `PHASE7_PERFORMANCE.md` |

## 剩余问题

1. **开窗面略显灰平：** 不再泛白，但通透感不足，见“原石材质”一节。
2. **矿场的渲染成本最高：** 真机帧率未知。降级手段已经列出，但没有启用。
3. **未改为正交相机：** 原因见 `PHASE7_PLAN.md` 第 0 节。
4. **次表面散射为近似：** 没有真正的体积散射；很薄的边缘透光依靠 emissive 近似。
5. **晶粒斑驳：** 在 2 倍局部图中可以看到，在部分屏幕上可能显得略“磨砂”。没有在真实屏幕上评估过。
6. **工位设备的形态**仍是简化模型（v1.0 已注明），本阶段只加了表面细节，没有改变结构。
7. **真实设备上的阴影闪烁：** 已在代码层面做了纹素对齐，但没有在真实 GPU 上观察过。

# Phase 7 实施计划 — 工业级视觉升级

> 本文写于 Phase 7.0 基准建立之后，记录检查代码时实际看到的结构，以及据此做出的取舍。

## 0. 起点（实际检查结果）

- v1.0 已通过 PR #1 合并到 `main`。Phase 7 在开发分支 `claude/amazing-mccarthy-q74aal` 上进行：该分支从最新 `main` 重新建立，`main` 不会被直接改动。
- 技术栈：Vite + TypeScript（strict）+ three 0.170，源码在 `src/`，发布构建在 `play/`。
- **相机：** 使用的是透视相机 + OrbitControls（`CameraRig`），不是正交相机。改成正交相机会影响全部 12 幕的镜头关键帧、缩放边界和热点投影，风险高、收益低。因此本阶段保留透视相机和现有镜头关键帧，不做改动。如果确实需要正交相机，应单独立项。
- **场景结构：** 8 个工位排布在一条直线上，每一幕只显示用得到的工位。矿场是一个独立的方形沙盘（`props/Mine.ts`）。
- **动画绑定：** 挖掘机动画通过 `Director.setArm()` 绕 z 轴旋转三个组：`boom`、`stick`、`bucket`。原石的抓取位置由 `bucket` 局部坐标 (0.08, 0.05, 0) 推算。只要这三个组的轴心与长度不变，动画就不受影响。

## 2. 主要视觉瓶颈（按优先级）

| 级别 | 问题 | 根因 |
|---|---|---|
| P1 | 矿坑台阶呈锯齿状 | 方形网格（100×100）上的陡坎，坎的走向与网格斜交 |
| P1 | 挖掘机履带悬空在台阶上 | 机身长度大于一级台阶的宽度，地面没有作业平台 |
| P1 | 侧面岩层呈马赛克色块 | 颜色按顶点计算，侧墙竖向只有 14 段 |
| P1 | 翡翠成品手镯的绿色偏移与其他工序不同（0.18 对比 0.08） | 违反“同一块原石材质连续”的要求 |
| P1 | 手镯与开窗面上有碎片化的条状高光 | 默认的 RoomEnvironment 由许多小方块灯组成 |
| P2 | 石皮像海绵，有虫状起伏 | 13 与 31 频率的凹凸幅度过大，并带有大块白斑 |
| P2 | 翡翠底色发白、偏粉笔感 | 基础反照率过高 |
| P2 | 树是“棒棒糖”造型；挖掘机和卡车是方块玩具 | 几何过于简单 |
| P2 | 工位机身是空白的大白盒，钢材是平坦的灰色 | 没有制造细节，也没有表面纹理 |
| P2 | 背光预设与聚光几乎没有区别 | 环境反射太强，盖过了方向光的变化 |
| P3 | 键盘提示文字被底部操作栏挡住（v1.0 遗留） | `bottom: 150px` 小于操作栏高度 |

## 3. 实施方案

### 7.1 矿场环境
- 地形改用以矿坑为中心的**椭圆极坐标网格**：台阶边缘与顶点行对齐，不再出现锯齿。网格外圈映射到方形边界，四个角点会被精确插入。
- 台阶剖面依次为圆滑坎顶、陡峭岩面和碎石裙。每一级台阶的高度不同，边缘有各自的起伏。
- 运矿坡道沿坑壁盘旋而下；草地上有一条车辙土路通向卡车。
- 挖掘机下方是平整的作业平台，高度与 v1.0 的地面高度相同，所以抓取原石的位置不变。
- 侧面直接取地形边缘的顶点生成，保证完全贴合。
- 程序化地表材质 `TerrainMaterial`：
  - 逐像素计算地层（五种岩层，厚度不均，带褶曲和夹缝）、草地、台阶碎石、道路、池边湿泥。
  - 粗糙度和法线扰动按地表类型分别设置。
  - 环境光遮蔽在构建时烘焙到顶点。
  - 不使用任何贴图文件。
- 碎石和巨石：一个 InstancedMesh，使用多面体碎块几何，颜色按实例变化。
- 树冠由四团平滑块组成，顶部亮、底部暗，颜色按实例变化；另加低矮灌木。全部用 InstancedMesh 绘制。

### 7.2 设备
- **挖掘机：**
  - 履带板沿跑道形路径排列，带支重轮、驱动轮和导向轮。
  - 转台、发动机罩上的百叶、排气管、圆形配重、带立柱的有色玻璃驾驶室、扶手。
  - 动臂是弯曲的箱形截面；斗杆有尾部延伸；铲斗由弧形斗壳、侧板和四颗斗齿组成。
  - 液压缸：双动臂缸、斗杆缸和铲斗缸。缸筒挂在父组上，活塞杆按子组的角度伸缩。
  - `Excavator.sync()` 是适配层，由 `Director.setArm()` 在每帧调用。
  - 轴心和长度保持不变。
- **卡车：** 车轮由轮廓旋转生成，有轮毂和后轮双胎；底盘、发动机罩、格栅、驾驶室玻璃、带加强筋的车斗、遮护板；车斗里装着碎石。
- **工位机身：** 统一加上门板缝、螺栓和踢脚板（`bodyDetail`）。
- **金属表面：** 拉丝不锈钢和磨料砂轮使用程序化纹理（`materials/surfaces.ts`），生成后长期共享。
- **控制 draw calls：** `mergeByMaterial()` 把同一刚体组内、材质相同的静态网格合并成一个。运动部件、带名字的网格和带热点信息的网格不参与合并。

### 7.3 翡翠材质
- 保留原有的“石头坐标系”采样方式。这是材质连续的根本：所有切块的纹理都是同一块石头内部坐标的函数。
- **石皮：**
  - 颜色为黄褐的砂质皮壳，带灰白的淋滤斑和深色风化斑。
  - 细密的砂粒斑点取代原来的大白斑。
  - 凹凸由宽缓的风化凹坑加上细颗粒构成，不再呈虫状。
- **玉肉：**
  - 底色调成半透明的灰绿，降低反照率，避免粉笔白。
  - 中绿与深绿略降饱和度。
  - 棉絮减弱。
  - 加入细微的晶粒斑驳：硬玉是多晶集合体，不是玻璃。
- **绿色偏移：** 所有工件统一使用 0.12。成品手镯不再单独加绿。
- **散射：** 次表面散射仍是近似做法：边缘透光（emissive）+ transmission + attenuation。**这不是物理级模拟**。

### 7.4 灯光
- 灯光参数集中在 `LIGHTING`（`scenes/Studio.ts`）：hemi / key / fill / rim、环境强度、色调映射、曝光。
- 新的反射环境是程序化的“珠宝摄影棚”：灰色无缝背景，加上顶部大柔光箱、两条竖向灯条和一块低位反光板。PMREM 只生成一次。
- **色调映射 A/B：** 用同一镜头对比 ACES 与 Neutral，最终保留 ACES。原因：Neutral 会把绿色推向荧光感，还会把白色地面变成奶油色。
- **阴影：**
  - 阴影框按阴影贴图的纹素对齐（在光源空间里对齐），镜头在工位间移动时阴影边缘不闪烁。
  - 仍是一盏投射阴影的方向光；分辨率按画质档位分级。
- **后处理：** **不启用**。原因：
  - 地形环境光遮蔽已经烘焙，接触阴影是现有的贴片。
  - SSAO / GTAO / Bloom 在中端手机上开销较大。透射通道又会把场景多画一遍，叠加后处理的成本更高。
  - 不加后处理也就不存在“需要关闭的后处理”。调试接口 `__jade.look({ toneMapping, env })` 可以切换色调映射和反射环境，用于对比和回退。

### 7.5 展厅
- 背光预设会降低环境反射（×0.4），并提高手镯的边缘透光，与聚光、柔光形成明显区别。
- 托架改为暖灰褐色的天鹅绒，给绿色手镯提供对比。
- 自动环绕、暂停状态和镜头逻辑都不改动。

### 7.6 回归与发布
- Playwright：21 项测试，桌面与移动各跑一次。
- after 截图：与 before 完全对应。
- 性能：对比每幕的 draw calls 和三角形数，结果见 `PHASE7_PERFORMANCE.md`。
- 发布构建：在 Pages 子路径下验证资源加载。
- 更新文档，并提交 Pull Request（不自行合并）。

## 4. 不做的事

- 不改为正交相机（原因见第 0 节）。
- 不增加后处理链。
- 不引入任何外部模型、贴图或 HDR 文件：所有内容都是程序化生成的，部署仍然只有静态的 JS 和 CSS。
- 不改动工艺流程、文字内容或交互逻辑。
